# 見た目の進化ラウンド（v144）変更・見送り記録

実施：2026-11-27。本人の指示「見たからに進化した感じにして」。
これまでのラウンド（正しさ・保持・手触り）に対し、今回は「開いた瞬間に目で分かる格上げ」が狙い。
変更前後のスクリーンショット（390×844）を比較し、動きは実駆動で computed style と transform の実測により確認した。

## 変更内容

- **ロック／タイトル画面（第一印象）**
  - キービジュアルに Ken Burns 風の緩やかなドリフト（30秒周期・scale 1.03→1.10）を追加。明朝タイポグラフィとキービジュアル自体は不変。
  - ランプの位置（68%・37%）に暖色の光だまりを重ね、8.5秒周期で呼吸するように明滅（kvGlow）。
  - 蝶の舞いをロック画面専用の flutLock に差し替え、横方向への漂いと速度差（9.5／12.5／15秒）で奥行きを出した。ホーム側は従来の flut のまま。
  - 登場時の振付を追加（boot クラス）：錠→時計→タイトル→通知→ボタン→ヒントが 0.02〜0.54秒の遅延で順に立ち上がる（lockIn）。
- **ホーム画面**
  - 壁紙グラデーションに右上の暖色の光だまり（radial-gradient）を1層追加。
  - 全アプリアイコン（ドック含む）に ::after でツヤ（上部の sheen＋内側のハイライト／影）を追加。
  - ウィジェット類（カレンダー／解剖メモ／BGM／ニュース／設定カード）の影を 0 12px 26px 系の二重影に深めた。
  - 写真ウィジェット：画像が24秒周期で静かにズーム（photoDrift）＋下部スクリムでラベルの可読性を上げた。
- **チャット**
  - 新着の吹き出しに出現アニメ（rowIn：下から 7px＋scale .96→1、.27秒）を追加。発火は実追加パスだけに限定した：本編は replaying フラグで履歴復元時を除外、フリーチャットは新設 freeRestoring フラグで renderFreeLog の復元時を除外。入力中表示（typingRow／フリー送信の typing 行）も対象。
- **Instagram**
  - 投稿写真（単枚・カルーセルとも）に .45秒のフェードイン（imgFade）を追加し、実物の画像読み込みの見え方に寄せた。
- **prefers-reduced-motion**：今回追加した全アニメーションを既存の配慮ブロックに合わせて無効化（実測で確認）。

## 見送った候補と理由

- **ロック解除の動き**：既存でズームフェード（.opening、v69）が入っており格として十分なため変更なし。
- **画面遷移（.view.on の vin）**：v120 で Tinder 版から移植した push スライドが既に統一されており、差し替えは格上げにならないため維持。
- **IG のダブルタップハート／ストーリー**：igbig のバーストとプログレスバーが既存で実装済み。ストーリー画像へのズームは実物 IG の作法に無いため見送り。
- **サイドトークへの吹き出し出現アニメ**：読み取り専用の履歴表示で実追加が起きないため対象外。
- **ホームの蝶**：ロック側と動きを揃える案もあったが、壁紙の静けさを保つため従来の flut を維持。

## 検証結果

Playwright 実駆動（iPhone 390×844・タッチ）で 32 項目全 PASS、JS エラーゼロ。
- 新規状態：各アニメーションの animationName と KV transform の経時変化を実測。全9アプリ到達。
- v143 形式の旧セーブ（idx=34・履歴12行を v143 実ビルドで作成）：履歴が復元され、履歴行には出現アニメが付かず、次の実メッセージだけに付くことを確認。
- クリア済み相当セーブ（フリーログ付き）：復元行はアニメなし、自分の送信と彼の返信はアニメあり。
- reduced-motion 環境：追加アニメーション全てが none になることを確認。
- 本編の台詞・数値・解放条件・LSKEY・写真割り当て・新規セーブ項目はいずれも不変（セーブ項目の追加なし）。
