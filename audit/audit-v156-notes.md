## ロック画面の整理（変更前 → 変更後）
本人の実機スクショ（2026-11-28 20:39、作中 6月25日・22:43 のセーブ）が変更前の実物。
- 変更前：実機ステータスバー → 帯（蝶＋題字）→ **作り物のステータスバー（22:43＋電波/Wi-Fi/電池）** → 錠 → 日付 → 時計 → **題字の重複（알고 있어도／わかっていても＋金の罫）** → **浮遊する灰色の蝶×3** → 通知×3 → ライト → ヒント
- 変更後：実機ステータスバー → 帯（題字はここに一本化）→ 錠 → 日付 → 時計 → 通知 → ライト → ヒント
- 対処1（ステータスバーの二重表示）：入口（ロック）表示中はページ内ステータスバーを出さない（`.statusbar.off` を showView で切替、初期表示も off）。根拠：ロックでは作り物のバーの時刻（22:43）が直下の大きな時計と完全重複し、実機のバー（20:39）と並ぶことで最もフェイクに見えた。ホーム／アプリ画面では、バーの時刻は作中スマホの時計として機能し、各画面のヘッダーもその前提で組まれているため従来どおり残した（実測で全画面到達・表示を確認）
- 対処2（題字の重複）：ロック内の `.lock-title`（알고 있어도／わかっていても／金の罫）を撤去し、題字はページ見出しの帯（金の蝶＋明朝＋金の罫）に一本化。identity（明朝＋金の蝶）は帯側で維持
- 対処3（浮遊する蝶）：ロック内の `.wall-butterflies`（灰色シルエット×3＋flutLock の漂い）を撤去。ホーム側の蝶は今回の指摘対象外（壁紙の質感として残置、報告で見送り明記）
- 対処4（積み重ね）：上記に加え、バーが消えた分だけ錠の上マージンを 52px → 34px 基調に詰めた。通知カード自体は実物 iOS 通知の再現として不変
- 撤去した要素の CSS／登場アニメーション／RM リストの参照も全て掃除済み（`.lt-*`・`.lock-title`・`flutLock`・`#v-lock .wall-butterflies` の死ルールなし）
