# v158 監査ノート ― 音・SE ラウンド（いいね SE の統一）

## 前提の訂正（実測監査の結果）
本ラウンドは「触った時の効果音が無い」という前提で開始したが、実物を確認すると **v7 で効果音基盤が既に実装済み**だった：
- 基盤：`sfxPlay()` ＋ 初回 pointerdown で立つ `sfxArmed` ゲート（自動再生ポリシー準拠。BGM の startMusic と同じ初回タップ起点）＋全体ミュート `S.mute`
- 既存の音（全て波形合成のオリジナル音源、assets/sfx/）：送信 send／受信 receive／通知 notify／着信 ringtone（ループ）／通話接続 connect／通話終了 callend／ロック解除 unlock／キーパッド tap／アンビエント4種（bar・rain・room・sea、場面連動）
- 既存の配線：本編の選択肢送信・ジェオン台詞の受信、フリーチャットの送信・返信（初回のみ）、ノイズバナー到着、通話発着信、電話キーパッド、ロック解除、ストーリーのハート（tap で代用）
- 設定：ホーム「演出設定」カードに効果音トグル（#set-sfx）＋効果音量スライダ（#sfx-vol）が既にあり、`S.sfxOn`／`S.sfxVol` としてセーブに永続化済み（v49 で音量の範囲是正済み）

## 本ラウンドで直した実害（無音だった「いいね」系）
監査で無音だったのは「いいね」系だけだった。専用の **like ポップ** を波形合成で新規作成し、付ける時だけ鳴るよう統一した：
- 音源：`assets/sfx/like.mp3`（2,239バイト、0.11秒、モノラル44.1kHz）。正弦波の周波数エンベロープ 950→520Hz＋2倍音の減衰で「泡が弾ける」ポップ。ピーク -6.4dB／RMS -19.8dB（既存 tap：ピーク -8.2dB と同水準）。再生ゲイン SFXG.like=0.5（tap 0.32 より少しだけ前に出す）
- 配線（全て「いいねを付ける時だけ」。外す時は無音＝既存の vib の作法と一致）：
  1. IG フィードのいいねボタン
  2. IG フィードのダブルタップ（新規に付いた時だけ）
  3. IG コメントのいいね
  4. ニュースコメントのいいね（従来は vib すら無かった）
  5. ストーリーのハート：tap → like に差し替えて同系統に統一

## 方式の判断
- 依頼方針は「WebAudio 合成を第一候補」だったが、既存基盤が **波形合成した音源ファイル＋HTMLAudio 再生** で v7 から安定稼働しており、方式を混ぜる合理性がないため既存方式に統一した。追加の転送量は like.mp3 の 2.2KB のみ（v151 の軽量化と実質衝突しない）
- AudioContext は本作では未使用。自動再生ポリシーの等価保証は `sfxArmed` ゲート（初回 pointerdown 前は sfxPlay が完全に無力）で、検証Aで実測した

## 見送った音と理由
- **ストーリーの送り**：実物 IG は無音。送りに音を付けると実物の静けさを壊すため入れない
- **カカオのサイドトーク到着**：到着はノイズバナーの notify が担っている。二重に鳴らさない
- **コメント送信・保存ボタン・フォロー等**：実物 IG は無音で、本作でも装飾タップ音はキーパッド等の限定運用が確立しているため広げない
- **nao エンディングのフリーチャット**：未送信（送られない）仕様のため送信音が無いのは正しい挙動（検証中に確認。当初テスト側のシード違いで FAIL に見えたが製品側の仕様）

## 検証（Playwright 実駆動 390×844、検証スクリプト25項目＋全アプリ横断）
- A：初回操作前に sfxPlay を直接呼んでも発火ゼロ（sfxArmed ゲート実測）
- B：ロック解除で unlock 発火、C：本編の選択肢送信で send／ジェオン台詞で receive 発火、D：バナー到着で notify 発火
- E：IG フィード いいねボタン→like、取り消し→無音、ダブルタップ→like、コメントいいね→like
- F：ニュースコメントいいね→like
- G：設定で効果音 OFF → いいね・直接 sfxPlay とも完全無音、OFF がセーブに永続化、ON に戻してリロードしても保持
- H：旧セーブ（v7 以前形式の最小セーブ＋galFav 文字列等の壊れ形状）で起動・ロック解除とも正常、sfxOn は既定 true に補完
- I：フリーチャット（drama エンディング）で送信 send／返信 receive 発火
- 全アプリ到達（news/kakao/ig/cal/notes/pov/epi/calllog）、全コンテキストで JS エラーゼロ
- 物語・台詞・数値・解放条件・LSKEY・セーブ形式は不変。新規セーブ項目なし。カメラ／ギャラリー復活なし

## 実機でのみ最終確認できるもの
- like ポップの音色・音量感（BGM と重なった時の聞こえ方）はエミュレーションでは判定できないため、本人の iPhone での体感確認が残る
