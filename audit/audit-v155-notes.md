# v155 監査ノート ― ギャラリー削除＋他アプリ リアル寄せラウンド

本人の確定指示（2026-11-28）：「写真アプリが必要ない」「他をリアルに」。

## 1. ギャラリー（写真アプリ）の完全削除

削除した機構（呼び出し・残骸とも残さない）：
- ホームの「사진」アイコン、ギャラリー画面（#v-gallery）そのもの
- 写真ビューア（前後ナビ／フィルムストリップ／ダブルタップズーム／スワイプ送り）
- お気に入り（galFav 永続化・バッジ）、削除→「最近削除した項目」（galDel・復元フロー）
- 表示モード切替（galMode：日／月／年／全て）、iOS風共有シート（#gsh-sheet 一式）
- 関連 CSS 全て（.gal-* 群、#gal-view のシマー、シート土台の #gsh-sheet セレクタ群）
- showView の暗色リスト・画面遷移後始末・シマーの .ld 連携からのギャラリー分

付け替えた飛び先：
- ホームの写真ウィジェット（蝶の部屋の写真）→ Instagram のジェオンのプロフィールを開き、解放済みなら該当投稿「butterfly」の詳細まで開く（未解放時はプロフィール止まりを実測）
- カカオ 더보기 の「앨범」項目 → 項目ごと削除（アイコン定義も除去）
- カカオのドロワーの「写真を見る」→ 実物カカオどおり、このトークで送受信した写真（S.free の meimg／jimg）だけを集めるメディアビューア（#media-view）を新設。新しい順グリッド＋タップで拡大＋キャプション表示、写真ゼロなら空状態。画面遷移で自動で閉じる

残したもの：
- カカオ＋パネルの写真選択（アルバムシート）はギャラリーとは独立に動作していたため不変。素材一覧は `GAL` → `LIBPHOTOS` と改名し、ピッカー専用の素材として存置（解放条件は従来どおり calU 連動）
- 画像ファイルは削除ゼロ：GAL 収録の17枚は全て IG投稿・ストーリー・ニュース等からも参照されていることを1枚ずつ確認した
- セーブ互換：旧セーブの galFav／galDel／galMode は読み込み時の正規化で従来どおり無害に処理され、以後は参照されない。LSKEY・セーブ形式の骨格は不変

## 2. 他アプリのリアル寄せ（監査結果）

現行 v154 を実駆動し、全アプリのクリック可能要素を総当たり（観測可能な変化が無いものを抽出）＋疑わしい4件を正規フローで再検証した。

- 検出された「無反応」は全てプローブの人工物か仕様どおりの不活性だった：範囲スライダ（クリックでは値が変わらない）、編集モードでのみ意味を持つ「完了」、検索キャンセル（検索バーを開いていない時）、カルーセルの先頭での「前の写真」（実物IGも巻き戻らない）、ロック中のカレンダー予定・後日談行（タップ不可が仕様）、既に選択中のタブ
- 再検証で実働を確認：IGストーリー（トレイのビンナ／ソルアはストーリーが無いため実物準拠の案内トースト。ジェオン／なおは正常に開く）、フリーチャットのスタンプ送信、電話キーパッドの数字入力、チャットの送信
- 結論：残るアプリに「押しても何も起きない・表示だけの飾り」の実害は検出されなかったため、本節での変更はギャラリー削除に伴う付け替え（上記）のみ。新しいアプリは追加していない

見送った候補：
- カカオヘッダーの音楽アイコン等、案内トーストで応じる要素：本作の確立した作法（v50〜）であり実害ではないため維持
- IGカルーセルの端でのループ再生：実物IGに無い挙動のため入れない
