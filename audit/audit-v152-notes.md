# v152 監査ノート ― 新規導入6スキルによる UI 作法監査と改修

対象スキル：web-design-guidelines（Vercel Web Interface Guidelines）／performance／core-web-vitals／accessibility／playwright-cli／better-icons。
計測はローカル配信＋ Playwright（Python、iPhone 390×844・タッチ）で実駆動。本編・台詞・数値・解放条件・LSKEY・セーブ形式・写真割り当ては不変。新規セーブ項目なし。

## 直した項目

### 1. CLS 0.28 の解消（core-web-vitals / performance）
- 原因：ギャラリー共有シート（#gsh-sheet）とカレンダー予定詳細シート（#cal-sheet）の土台 CSS が v90 の**実行時注入スタイル**の中にあり、注入が効くまでの間、シートの div が素のブロックとして画面中央に描画され、注入後に absolute 配置へ跳ねていた（実測：y=320/h=43.5 → y=102/h=740、ずれ 0.28）。
- 修正：土台7ルール（配置・背景・パネルの初期 transform 等）を**静的 CSS 側へ移設**し、注入文字列からは削除（旧機構の残置なし）。開閉の実働は旧セーブ実駆動で確認（カレンダー詳細シートは実データで開閉・スクショ確認、共有シートは .on／transform／閉鎖を確認）。
- 他の注入スタイル（カルーセル／プロフィール編集／通知行など）は非表示ビュー内の要素専用で初期描画に影響しないため移設対象外。

### 2. アニメーションの作法（web-design-guidelines：transform/opacity のみ）
- `#toast` の `transition:.35s`（= all 相当）を `opacity, transform` の明示へ。
- 解明度メーター2種（.meterbar / .paramline .mb）の `transition:width` を **scaleX** に変換（CSS 3ルール＋初期マークアップ2箇所＋JS の代入2箇所）。実測：kai=42 でバー実幅 90px／トラック 214px＝42%、computed transform = scaleX(0.42)。見た目の伸び方は従来どおり。
- 設定スイッチ（.ios-sw）のノブ `transition:left`＋`left:21px` を **translateX(19px)** に変換。実測：on で matrix tx=19、off で none、transitionProperty=transform。
- 着信画面の波紋（ringpulse）の `box-shadow` 無限アニメーションを、**::after の scale＋opacity** に変換（66px ボタン＋22px 拡散 ≒ scale 1.67 で等価）。スクショで波紋の見え方を確認。
- あわせて、波紋を ::after に移したことで届かなくなっていた reduced-motion 側の停止ルールに ::after を追随させた（実測：RM 時 animation=none）。

### 3. タッチ作法（web-design-guidelines）
- `touch-action: manipulation` を button/input/textarea から全要素へ拡張（二度押しズーム遅延の排除）。`.lk-btn` の `touch-action:none`（長押し作法）はクラス指定が優先され従来どおり（実測で競合なし）。

### 4. アクセシビリティ（accessibility、実害範囲のみ）
- IG ヘッダーボタン `.igh-btn` が **23×23px** で WCAG 2.2 の最小 24px を割っていた → ヒット領域を **28×28px** に拡大（グリフの大きさ・並びは不変）。実測：IG 画面の 24px 未満ターゲット 3件 → 0件。ホーム／ギャラリーは元々 24px 未満なし（24〜44px 帯が 11件、iOS 作法の範囲）。
- キーボード操作時のフォーカス可視化を追加：`button:focus-visible, [role="button"]:focus-visible` にアウトライン（従来は :focus ルール自体が無かった）。タッチ操作では出ない。

### 5. アイコンの線の統一（better-icons の観点で棚卸し）
- 手描き SVG は系統ごとに均一だった：IC セット stroke 1.8／IG アイコン群 1.7 で統一。ただしプロフィールのタブ行で、grid アイコンだけ **1.6** で隣のブックマーク（1.7）と同列で揃っていなかった → **1.7 に統一**。差し替え（Iconify 取得）は系統の維持を優先し行わなかった（既存が実物 IG の線の細さに合わせてあり、外部アイコンに替えると系統が崩れるため）。

## 見送った候補と理由
- **INP の追加対策（フィード描画の分割・content-visibility）**：IG 表示のイベント時間は共有 VM のエミュレーションでは分散が大きく実害と断定できない。content-visibility は v140/v141 で確定した IG スクロール復元の高さ前提と衝突する恐れがあり、確定仕様を守るため見送り。
- **calflash（カレンダーの背景フラッシュ）**：1.2 秒・1回きりの背景色遷移で、transform/opacity 化には疑似要素の重ねが要り見た目のリスクが見合わない。
- **コントラスト**：自動スキャンの低コントラスト検出は大半が写真上の文字（背景推定の誤検出）。実テキストのグレー（コメントの「すべて見る」3.28:1 等）は実物 IG のグレーそのもので、実物寄せの意図として維持。
- **生成 img の alt 一括付与**：装飾アバター等で、ゲーム文脈の実害が薄く、テンプレート全域に触るリスクが見合わないため見送り。
- **LCP の追加対策**：KV はインライン CSS の背景で発見は即時、転送量は v151 で圧縮済み。ラボ値の分散が大きく追加変更の根拠なし。
