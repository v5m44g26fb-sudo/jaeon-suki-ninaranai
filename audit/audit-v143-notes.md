# リアル化ラウンド第4弾（v143）棚卸し・修正・見送り記録

実施：2026-11-27。本人の指示「もっと」（第4弾）。観点は「操作の手触り・応答の質」。
開始前に git pull で最新化済み（v142 が最新だった）。

## 実測で見つけた欠陥と修正（v143）

1. **IGコメントのいいねがリスト全再描画だった**：ハートを押すたび `renderCmList()` で
全行を作り直していた（投稿のいいねはその場更新なのに、コメントだけ方式が違った）。
全再描画はスクロール中のタッチを中断し得る。その場更新へ変更：ボタン自身の class／SVG fill／
件数メタだけを書き換え、ハートのポップ（igpop 流用）も追加。作り直された「返信する」ボタンは
`bindCmReplies` で結線し直す。実測：同一ノードのまま・scrollTop 150→150 不変・件数 31→32・
返信メンションも継続動作・解除で保存配列も空に戻る。
2. **写真ピッカー（#albumpick）にシートアニメーションが皆無**：display の即時切替で
パッと出てパッと消えていた。他シートと同じ方式（背景フェード＋パネルのスライド.38s）に統一。
開閉の全経路（✕／背景タップ／写真選択）は従来どおり class 切替のみで、アニメは CSS 側で完結。
実測：入場・退出とも rAF サンプリングでスライドを確認、写真送信も従来どおり動作。
3. **商品シート（#ksp-sheet）の退出アニメーションなし**：入場だけ keyframes（kspUp）で、
閉じる時は即消えだった。スライド方式へ作り替え、旧機構 kspUp は廃止（呼び出し・定義とも削除）。
実測：入場・退出ともスライドを確認。カート切替時の内容再描画でアニメが再生し直されなくなった。
4. **押下フィードバックの欠落**：実測（押下中の computed style 比較）で無反応だった箇所に
実物の作法どおり追加：戻るボタン（opacity.4）、解剖メモ行（背景 #f2f2f7）、ギャラリーのサムネイル
（opacity.72）、ホームのウィジェット2種（opacity.72）、iOSアラートのボタン（背景 #e9e9ee）、
プロフィールミュージック行、コメントの「返信する」／ハート（scale 1.22）、IGプロフィールの
スタッツ、ニュースのカテゴリチップ／コメントいいね、ストーリーのアイコン（scale.85）、
コメントシートの✕、商品シートの購入ボタン、写真ピッカーのサムネイル、通知バナー。
5. **慣性スクロールの表記統一**：残っていた容器（ニュースタブ／ギャラリー帯／IGハイライト／
チャットドロワー／通話メイン）に `-webkit-overflow-scrolling:touch` を追加。
モダン iOS では既定動作のため実害は無く、表記の統一のみ。

## 実測で健全だった項目（変更なし）

- **選択肢の連打**：座標ダブルタップで kai／idx／自分の吹き出しは各1回だけ適用（同期的に wrap を
外す設計）。最終選択も同方式で安全。
- **コメント送信のダブルタップ**：1件だけ投稿（送信時に欄を空にする設計）。
- **フリーチャット送信のダブルタップ**：1件だけ（freeBusy＋欄クリア）。
- **IG投稿いいね連打×5**：パリティ正常（766→767件、liked 終了）、その場更新。
- **トーストの連続表示**：2つ目が前のタイマーで早期に消えない（v47 の修正を実測で再確認）。
- **コメントシートの退出アニメーション**：rAF サンプリングで約.38s のスライドを確認。
- **シートのドラッグ閉じ**：grab 付き全シート（cm／ppl／sv／shr／bg／gsh／cal）に登録済み。
アクションシート系（act／fol／mk）は実物 iOS もドラッグで閉じないため対象外。
- **iosAlert の OK 連打**：iaCb を先に null 化してから呼ぶためコールバックは単回。
- **通話の行送り連打**：callResolve を先に null 化、単回解決。
- ストーリーのハート／カカオの反応チップ：その場更新で再描画なし。

## 見送った候補と理由

- **タブバー類（カカオ／IG）の押下状態**：実物のタブバーにも押下ハイライトは無いため追加しない。
- **スライダー類（音量・文字サイズ）の押下状態**：つまみ操作そのものがフィードバックのため対象外。
- **ホームバーの押下状態**：タップ対象ではないため対象外。
