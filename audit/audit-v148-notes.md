# v148 ホーム画面のデザイン世代監査ラウンド（残り3層の第3層）監査ノート

実施日: 2026-11-27 / 対象: v147 → v148
検証: Playwright（~/.venv-tools）実駆動、iPhone タッチエミュレーション（390×844 / 430×932 / 360×740、deviceScaleFactor 2）。検証スクリプトと前後スクリーンショットは /tmp/jaeon-v148/（drive.py / regress.py / savecheck.py、home-before-390.png / home-after-390.png ほか）。

## 監査の物差し

舞台は2021年なので、ホーム画面の様式を iOS 14 当時の実物に照らした。姉妹作品群のホーム作り直しで確定した知見（アイコンのツヤ＋深い影は iOS 6 作法で古く見える／現行世代はフラットな面＋柔らかい影1本）を本作にも適用する。本作は v144 で逆方向（ツヤと二重影の追加）をしていたため、その棚卸しが主眼。

## 変更した様式（変更前 → 変更後）

1. **アプリアイコンのツヤを撤去**（主眼）
   - 変更前: v144 の `.app .ic::after` が全アイコンに上部シーン（白グラデーション 0→60%）＋ inset 上端ハイライト（rgba(255,255,255,.38)）＋ inset 下部陰影を重ねていた。computed style 実測で3要素とも存在を確認。これは iOS 6 までのスキューモーフィックな作法。
   - 変更後: ::after ルール自体を削除（旧機構の残置なし）。アイコンの面は各アイコン固有の色・穏やかなグラデーション（IG のブランドグラデーション、写真のピンホイール等、iOS 7 以降の作法に属するもの）のみで構成される。実測: ::after の backgroundImage / boxShadow とも none。
2. **アイコンの影を柔らかい1本に**
   - `0 3px 8px rgba(0,0,0,.28)` → `0 2px 7px rgba(0,0,0,.20)`。
3. **ウィジェットの二重の深い影を単一の影へ**
   - 変更前: v144 の上書きで `.wid-cal/.wid-wide/.wid-music/.wid-news/.set-card` が `0 12px 26px rgba(2,6,16,.34), 0 2px 6px rgba(2,6,16,.20)` の二重影。
   - 変更後: 全カード（.wid-photo を加えた6種）共通で `0 6px 18px rgba(2,6,16,.20)` の単一の柔らかい影に統一。computed style 実測で全カード一致を確認。
4. **電話・設定アイコンをフラットな単色へ**
   - 電話: 縦グラデーション（#67e06a→#29c73a）→ 単色 #35c94a（iOS 14 の電話アイコンはフラットな緑）。
   - 設定（最初から）: 金属調グラデーション（#e8e8ec→#b9b9c0）→ 単色 #e8e8ed（実物は明るいグレーの平面にグレーの歯車）。
5. **バッジの作法を実物に寄せ、配置をアイコンの角へ固定**
   - 白縁なし・赤地白文字は従来どおり実物と一致（変更なし）。ただし従来は影付きで、配置が `.app`（グリッドセル幅）基準の `right:6px` のため、アイコン角からのズレが画面幅で変動していた（実測: グリッド側はアイコン右端超過が 360px→+0.8 / 390px→+4.5 / 430px→+5.8 とドリフトし、ドック側は −6 と内側に入って不揃い）。
   - 変更後: 影を外し、`right:calc(50% - 35px)` でアイコン中心基準に固定。実測で全幅・グリッド／ドックとも「右端超過 +5〜+5.5px／中心は角から −4.5〜−5px, +5px」に一致（幅非依存）。
6. **ニュースウィジェットの角丸を統一**
   - 16px → 20px（他の iOS 14 ウィジェットと同値）。

## 実測で当時の作法に合っていた項目（変更なし）

- **ドック**: 縁なしのフロストガラス（rgba(235,235,240,.34) + blur 20px saturate 1.6、角丸 27px）、ドック内アイコン 60px・ラベルなし。iOS 14 の作法どおり。
- **アイコンの寸法・角丸**: 59×59px・角丸 13.5px（比率 22.9%、実物の約22.4%に近似）。
- **絵柄の様式**: カカオ（黄地に茶の吹き出し）、カレンダー（白地に赤の曜日＋細字の日付）、メモ（白地に黄色の帯＋罫線）、写真（ピンホイール）は実物 iOS 14 アイコンの再現として成立。IG はブランドグラデーションが正。彼視点／後日談の穏やかな暗色グラデーションは iOS 7 以降の作法の範囲内。
- **ラベル**: 白文字＋ text-shadow で壁紙上でも可読（前後スクリーンショットで確認）。壁紙の暖色の光だまり（v144）は様式の世代と無関係な演出として維持。
- **写真ウィジェットの静かなズームと下部スクリム**（v144）: 世代の様式ではなく本作の演出として維持。

## 見送った候補と理由

- **設定アイコンの歯車グリフを塗りつぶしに変える**: 実物の設定アイコンは塗りの歯車だが、本作の線画歯車は SF Symbols 系の線グリフとして iOS 14 世代内でも通用する表現であり、面をフラット化したことで世代のズレは解消したため、グリフ自体は維持。
- **彼視点／後日談アイコンのグラデーション単色化**: 架空アプリのアイコンで、穏やかなグラデーションはフラット世代でも一般的な作法（App Store 等）。ツヤ撤去後は旧OS感がないため維持。
- **BGM ウィジェットの暗色ガラス**: iOS 14 の音楽ウィジェットとは別物の本作独自ウィジェットで、フラットなカードとして成立しているため維持。

## 検証結果

- 変更前後のスクリーンショット（390×844、先頭／スクロール状態）で様式の差を確認（白アイコン上部のテカリ消滅、カードの影の軽減、電話アイコンの単色化）。
- computed style 実測: ツヤ ::after = none、アイコン影・ウィジェット影は単一値、バッジは影なし＋配置固定（3幅で幾何実測）。
- 到達回帰: グリッド9アプリ＋ドック4アプリ＋ウィジェット2種（カレンダー／ニュース）の遷移とホーム復帰を全て確認。JS エラーは 3 幅ともゼロ。
- セーブ往復: 本編を5タップ進行（idx=4 を保存）→ リロード → 履歴が同件数で復元され、ホームも正常表示。本パッチは CSS と版数ノートのみで JS・LSKEY・セーブ形式に変更なし。
- 本編の台詞・物語の内容・数値・解放条件・LSKEY・写真割り当て・アプリの並びと導線は不変。新規セーブ項目なし。カメラは復活させていない。ロック／タイトル画面には触れていない。
