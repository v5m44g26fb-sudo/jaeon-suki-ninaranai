# 動きの質ラウンド（v146）棚卸し・修正・見送り記録

実施：2026-11-27。本人の指示「残り3層、全部回して」の第1層＝動きの質。
開始前に git pull で最新化済み（v145 が最新）。カメラは復活させていない。
v144 のタイトル振付・吹き出し出現・フェードインとは競合させず、カーブと尺の作法を揃える側に回した。

## ベースライン実測で確認した欠陥（v145 時点）

- **画面遷移に方向が無い**：showView の入場は全遷移共通の vin（右から14px＋フェード）で、戻る操作でも右から入っていた。旧画面は退出アニメーション無しで即消え。
- **シートの閉じが ease-out の長い尾**：開閉とも .38s cubic-bezier(.32,.72,0,1) で、閉じる時は速く始まって最後に這う（実測：97%到達後も約150ms尾を引く）。開く時も行き過ぎ（スプリング）は無し。
- **一覧の入場が再描画のたびに再生**：.nw-item／.povrow／.ig-post 等への一括 fadeup 指定で、renderNews() の再描画でも全行が再生される（実測で fadeup の再発火を確認）。時間差（スタッガー）も無し。

## 修正（v146）

1. **遷移の方向の対**：戻るボタン（.back／ストーリーの✕）のクリックを捕捉し、次の showView 1回だけ「戻り」として扱う。戻りは vinB（左から−16px）で入り、旧画面は byeB（右へ22px＋フェード）で退出。進みは従来の vin のまま、旧画面は byeF（左へ−14px のパララックス退出）。z-index は 入る画面2／進みの旧画面1／戻りの旧画面3 で重なりを制御（ID指定の z-index がある #v-lock 100・#v-call 120・#v-profile 130・#v-story 140 は従来どおり優先）。ロック画面が絡む遷移は退出を付けない（開錠ズームの既存演出と競合させない）。
2. **シートのバネと暗転の追随**：全シート（ppl／sv／cm／shr／bg／gsh／cal／act／fol／mk／ksp／写真ピッカー）とチャットドロワーで、開く時＝ .52s（アクションシート系は .44s）cubic-bezier(.3,1.14,.38,1) のスプリング（実測で最終位置を約3px行き過ぎて収まる）、閉じる時＝ .3s（同 .26s）cubic-bezier(.55,0,.85,.4) の加速カーブに分離。暗転は開く時に .42s で追随。gsh／cal／mk は実行時注入スタイル側の基本 transition も閉じカーブに合わせて編集（開く側は v146 の .on 上書きが高詳細度で効く）。ドラッグ閉じ（.dragging の transition:none）は不変。
3. **一覧の時間差入場**：一括 fadeup を止め（animation:none で上書き）、__casc ヘルパーを新設。初回表示のキーだけ .casc を付けて先頭から 42ms ずつずらして出す（最大8件分まで遅延）。再描画・再訪では再生しない。対象：IGフィード（igfeed）、ニュース（カテゴリ別／検索は一括キー）、解剖メモ、カカオのトーク一覧、彼視点／後日談の一覧、コメントシート（投稿別）、ギャラリーのグリッド（表示モード別）。検索入力中の再描画で再生しないよう、ニュース検索中はキーを固定した。
4. **ボタンの戻り**：押し込みは速く（:active 中の transition-duration を .05〜.06s に短縮）、離すとバネで戻るカーブ cubic-bezier(.34,1.35〜1.5,.64,1) に統一。対象：ホームのアプリアイコン、IG／コメントのいいねポップ（igpop のタイミング関数）、コメントいいねボタン、設定ボタン、ストーリーのフッターアイコン、＋パネルの丸ボタン、カカオの反応チップ、商品シートの購入ボタン。
5. **大きな写真のシマー**：読み込み中に光の帯（shimSweep、1.25s）が流れる表示を IG 投稿写真（.ig-imgwrap）、ストーリー、ギャラリーのビューア、ニュースのヒーロー画像に追加。capture 段階の load／error 監視で .ld を付け、帯はフェードして止まる。キャッシュ済みは sweep で即 .ld。ストーリー／ギャラリーは src 変更を MutationObserver で見て、未完了なら .ld を外して帯を再開する。帯は ::after で、IG のビッグハート（z4）やギャラリーのナビ（z5）より下に置いた。

## 検証結果

Playwright 実駆動（iPhone 390×844・タッチ）で検証し全 PASS、JS エラーゼロ。

- **方向**：進み（ホーム→カカオ）＝ vin で +14px から入場＋旧画面 byeF で左へ退出。戻り（チャット→カカオ、ニュース→ホーム、ストーリー✕→IG）＝ vinB で −16px から入場＋旧画面 byeB で +22px へ退出、を transform の実測で確認。
- **シート**：cm シート開く時に行き過ぎ（min y = −3px）を確認。閉じる時は 95% 到達 308ms（総尺 .3s 内で尾を引かない）。ドラッグ閉じも従来どおり動作。
- **時間差入場**：ニュース初回は .casc 付きで animation-delay が 0.084s／0.126s と増加、renderNews() 再描画では .casc が外れ animationName=none（再生なし）。IGフィード／ギャラリーでも .casc の初回付与を確認。
- **シマー**：jpg を3秒遅延させるサーバで実測。読み込み中は .ld 無し・::after が shimSweep で transform が実際に移動（−98.7→+245）、完了後は .ld が付き animation=none・opacity 0。IG投稿／ストーリー／ギャラリービューアの3面で確認（ニュースヒーローは同一機構）。
- **prefers-reduced-motion**：実測で、カスケード無効（.casc 付かない）、戻り遷移の animation=none、旧画面の退出クラスが付かない、シマーが animation=none、シートの transition が .01s になることを確認。
- **旧セーブ互換**：v145 の実ビルドで作ったセーブ（idx=4）を v146 で読み込み、idx／chap が一致して引き継がれることを確認。新規セーブ項目なし、LSKEY 不変。
- 全9アプリ到達、本編チャットのタップ進行（吹き出しの出現まで）も確認。

## 見送った候補と理由

- **IG 内タブ切替（フィード⇔プロフィール等）の方向**：showView を介さない内部再描画で、方向を付けるには描画側の作り替えが要る。今回の対象は画面遷移の対に絞った。
- **カレンダーの月送りアニメーション**：.cal-grid／.cal-pager の fadeup は月ページ単位の入場として自然で、再描画のたびに再生される性質も月送りでは実害が無いため維持。
- **トースト／通知バナーのカーブ**：v143 までの調整で尺・カーブとも実物寄りに収まっており、変更なし。
- **常時アニメーションの追加**：電池・重さ配慮のため見送り（追加したのは遷移・入場・読み込み中だけの一時的な動きのみ）。
