## 移植項目（優先順）と実装マーカー

### P1. チャット「一番下へ戻る」ボタン
- 現状：ジェオン側に無し（grep '一番下|scrollBtn|toBottom' = 0件）。
- 移植元：hiroto-tinder の LINE 実装（本トークで上スクロール時のみ入力欄上に丸ボタン浮動、タップで最新へ）。
- 実装マーカー：要素 id `chat-bottom-btn` を追加し、文字列「一番下へ戻る」を含むこと。パッチ後に grep で各1件を確認。
- 注意：タップ送りの自動スクロール（scrollFeed）と競合させない。ボタン表示判定は「ユーザーが上にスクロールしている間だけ」。MutationObserver を使う場合は値比較ガード必須。

### P2. メッセージ反応（カカオ風リアクション）
- 現状：無し（reaction系は偶発2件のみ）。
- 移植元：hiroto-tinder の DM 反応（吹き出しダブルタップでハート、長押しで ❤️😂😮😢😡👍 トレー、保存される）。
- ジェオン側の調整：カカオトークの実物仕様に寄せ、長押しトレー＋共感表示をメッセージ下部に小さく出す。保存は S に `reactions` フィールドを追加（旧セーブは Object.assign デフォルト補完で移行、LSKEY は据え置き）。
- 実装マーカー：関数 `renderReactionTray` と保存キー `reactions`。

### P3. 入力欄の＋パネル
- 現状：無し。移植元：hiroto-tinder の LINE ＋パネル（写真・カメラ等のグリッド）。
- 対象はクリア後フリーチャットの入力欄と、本編チャットのダミー入力欄。パネル項目は世界観に合わせ「사진（写真）／카메라（カメラ）／선물（ギフト）／송금（送金）」等の韓国カカオ風に差し替え。写真は既存 assets から選べる簡易ピッカーにし、フリーチャットへ画像送信できるようにする（機能追加に紐づく範囲）。
- 実装マーカー：要素 id `plus-panel`。

### P4. IGストーリービューアの実物寄せ
- 現状：ストーリー再生あり（openStory/renderStory、タイマー送り）。下スワイプ閉じ無し（swipe系 0件）。
- 追加：下スワイプで閉じる、長押しで一時停止（タイマー停止＋プログレスバー停止を明示）、離すと再開。既存のタップ送り（左右タップ）は維持し、旧タイマー処理と二重に進まないよう、後継を入れたら旧の自動進行呼び出しを止める。
- 実装マーカー：関数 `storyPause` / `storyResume`。

### P5. 写真ビューアのスワイプ送り
- 現状：ギャラリーはタップ拡大のみ。左右スワイプで前後写真へ移動、ピンチは対象外（過剰実装を避ける）。
- 実装マーカー：関数 `galSwipe`、ビューア要素 id `gal-viewer` への touch ハンドラ。

### P6. IG検索／探索タブ（追加候補）
- IG下部タブに検索（探索グリッド）を追加。既存投稿画像のグリッド＋登場人物アカウントの検索結果（ジェオン／ドヒョク／ソルア／ビンナ）。物語の解放状態と連動し、未解放の投稿は出さない。
- 実装マーカー：ビュー `v-igsearch`。

### P7. ニュースアプリ（任意・監査所見を見て判断）
- 韓国ポータル風ニュース＋アクセスランキング。内容は作中イベント連動（ギャラリー展の紹介記事など最小限）。世界観を壊す場合は見送り。

## 版数・公開手順（承認後）
1. 上記マーカーを1項目ずつ当て、各パッチ後に grep でマーカー件数を検証（0件または想定外なら全体を止める）。
2. 版数を v74 以降に上げ、ページ見出しの版数注記と README のバージョン履歴を更新。
3. `python3 -m http.server` で配信し Playwright（~/.venv-tools/）で全画面駆動：ロック→ホーム→各アプリ→本編タップ送り→選択肢→通話→IGストーリー→ギャラリー→設定。コンソールエラー走査、日付・曜日の整合、後半コンテンツの漏れ、テキストの見切れを確認。
4. `.nojekyll` の有無を確認（無ければ追加）。
5. push → Pages 反映を待ち、版数クエリ付きURL（例：`?v=74`）でライブ確認してから報告。
