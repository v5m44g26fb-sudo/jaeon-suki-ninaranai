# リアル化ラウンド監査ノート（v132〜v135、2026-11-26夜）

本人の指示「もっとリアル化」を受け、全アプリを実駆動で棚卸しし、「触ると分かる嘘」を優先度（状態＞触感＞見た目）で潰した記録。各版とも Playwright 実駆動（iPhone 390×844・タッチ）で検証し、ライブ配信物の md5 一致まで確認済み。本編・台詞・数値・解放条件・LSKEY・写真割り当ては全版通じて不変。

## 直したもの

- **v132 ホーム／電話**：ホームのカレンダー・写真ウィジェットがタップ無反応だった（ニュースウィジェットだけが開いた）→ 実物どおり各アプリを開くよう統一。電話の通話履歴の行と ⓘ が完全無反応だった → タップで詳細アラート（日時・通話時間。本編の発生日 c1=4月16日／c2=6月25日／不在着信=6月26日と一致させた）。
- **v133 IG／チャット**：ストーリーの無いユーザー（ビンナ／ソラ）にグレーの「既読」リングが付いていた（実物ではグレーリング＝見終わったストーリーが存在する意味）→ リング無し表示に。本編チャット下部の入力欄・絵文字・# が無反応だった → 入力欄タップでフィードと同じ前進、絵文字／# は案内トースト。
- **v134 ロック画面**：通知は表示のみで、タップしてもホームにしか行けなかった → 実物 iOS どおり、解除後に該当アプリと詳細まで開く（カカオ→トーク一覧、解剖メモ→そのメモの詳細、カレンダー→その予定の詳細シート、天気→ニュース。通知バナー v90 の遷移マップと統一）。
- **v135 カメラ**：モード表示（슬로모션／비디오／사진／인물／파노라마）と反転ボタンが無反応だった → モード切替を実装。ビデオではシャッターが赤丸になり、押すと ●REC タイマー＋角丸モーフ、再押しで停止。反転でファインダーを左右反転。

## 見送った候補と理由

- **ホームのカカオアイコンの「✓」バッジ**：未読0・クリア済みのときに完了印として出す v106 の意図的デザイン。数字を騙る表示ではないため維持。
- **解剖メモ／彼視点／後日談の件数バッジ**：解放数を出す v69 の設計で、アプリ内のコレクション件数表示と一致している。未読バッジの偽装ではないため維持。
- **IG の DM ボタン類**：タップで「メッセージはカカオトークで」と案内する v50 以来の本作の作法。無反応ではないため維持。
- **カメラのサムネイルタップ**：この作品のカメラは写真を保存しない設計で、サムネイルはファインダーと同系の表示として既に整合している。保存されない写真のビューアを偽造しないため見送り。
