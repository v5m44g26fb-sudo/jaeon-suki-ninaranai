# 🦋 パク・ジェオンを好きにならない件

韓国ドラマ『わかっていても』（알고있지만、）の世界を題材にした、スマホ風SNSファンゲーム（単一HTML＋画像アセット、フレームワークなし）。

**これは二次創作のファンメイド作品（創作フィクション）です。原作ドラマ・放送局・出演者等の実在の人物・団体とは関係ありません。**

▶ **プレイ:** https://v5m44g26fb-sudo.github.io/jaeon-suki-ninaranai/

## あらすじ / 物語の範囲（完結編）
主人公はホンソ大学彫塑科4年の「なお」（ユ・ナビの位置）。元彼の個展で破局した夜、バーで蝶のタトゥーの男――パク・ジェオン（彫塑科2年、再受験＋休学で同い年）と出会う。
- プロローグ：元彼の個展／破局
- 第1章：バーでの出会い（コースターの蝶、「蝶、見に行く？」）
- 第2章：学科の飲み会で再会、作業室、カカオトーク開始
- 第3章：曖昧な関係の始まり〜なおの誕生日〜一度目の別れ（「いつも壁を作ってる」）→ 第1部完
- 第4章：別れの余波〜ギャラリー展の助手としてジェオンが戻る〜ソルアの宣戦布告
- 第5章：合宿（ドヒョクの地元、観覧車、ささやきゲーム、ドヒョクの告白を断る）〜帰京後のすれ違い
- 第6章：「付き合おう」（対抗心だと見抜く）〜雨の夜の泥酔詰問〜「二度と現れないで」
- 最終章：作品の破損と修復の手伝い〜ギャラリー展〜最終選択

### エンディング（3種・最終選択と解明度で分岐）
1. **END「わかっていても」**：傷つくのを承知で「付き合おう」と答える（ドラマ準拠）
2. **END「一人で進む」**：誰も選ばず、自分の作品と進路（パリ）を選ぶ（原作準拠）
3. **特別END「好きにはならない」**（解明度が高い場合に解放）：全部わかった上で「好きにはならない」と伝える静かな別れ。エピローグでは彼の兵役の気配にも触れる

到達したエンディングは「解剖メモ」下部のエンディングコレクションに記録されます。

## 遊び方 / システム
1. ホーム画面から「カカオトーク」を開き、パク・ジェオンのトークを開くと物語が始まります。**v5からはタップ送り制**です：メッセージは1通ずつ表示され、画面をタップすると次が表示されます（相手の文は「入力中」の間を置いて届き、重要台詞の前には沈黙の間が入ります）。ホームの「演出設定」で自動再生や速度（ゆっくり／ふつう）に切り替えられます。チャットの ▶ 長押しで早送りモードになります。
2. なおの返信は3択式。選択でパラメータ「解明度」と「心の距離」が変動します。試す・採点する・理由を聞く（ENTP-T的）返しほど、彼の仕組みが見えてきます。
3. **解剖メモ**：各章のキー場面で、彼の心理を分析したメモが解放されます（全9件）。壁の正体、感情と言語化のズレ、間欠報酬、追う側と逃げる側のループ、「壊してみたい」の検証結果、喪失でしか動けない仕組み、「壁は付き合っても消えない」など。
4. Instagram：ジェオンとなおの投稿が物語の進行で解放されます（投稿をタップすると詳細・コメント表示）。特別END到達時のみ解放される投稿もあります。
5. カレンダー：3月〜7月の一学期タイムライン。進行に合わせて解放。「兵役：未定の予定」という小ネタも……。
6. 友人ビンナ／彫塑科グループ／ドヒョク／ソルアのトークは読み取り専用のサイド要素です（友人トークは短め）。
9. **BGM（v4）**：ドラマOSTが場面に合わせて流れます（タイトル／バー＝「Butterfly」、夜のアトリエ＝「Whisper」、雨の章＝「Heavy Heart」、ギャラリー／最終選択＝「Love Me Like That」ほか）。ホーム画面の音楽ウィジェットでON/OFFと音量を調整でき、通話シーンでは自動で音量が下がります。
10. **彼視点（v4）**：各章の進行で解放されるジェオン視点の短編コレクション（全5編）。彼の内面も「全部は言語化できない」造形で、行動と断片で描きます。
11. **エンディング後フリーチャット（v4）**：クリア後のカカオトークで自由入力のやり取りができます。到達したエンディングでトーンが変わります（ドラマEND＝恋人だが壁は残る距離感／原作END＝返信はほぼ来ない／特別END＝トーク自体が終了済みで送信できません）。キーワード反応と回数キャップあり。
12. **IGストーリー（v4）**：章連動でジェオン／なおのストーリーが増えます（2021年様式のストーリービューア）。第2部のIG投稿も3件追加。
13. **プロフィールの変化（v6）**：ジェオンのカカオプロフィールは物語の進行で変わります。状態メッセージ（상태메시지）とプロフィールミュージックが章ごとに切り替わり（序盤「작업 중」＋「Love Song」→ 曖昧な関係の頃は状態が消えてOSTの「Whisper」に → 助手復帰で「전시 준비 중」→ 雨の章のあとは全部消えて → 最終章で蝶に触れる短い一文と「Love Me Like That」）、プロフィール写真と背景も節目で差し替わります。プロフィール画面を開いたときに、静かに気づく形です。
14. **端末の生活感（v6）**：ステータスバーとロック画面の時計は、実時刻ではなく物語内時刻と連動します。バッテリーは一日の進行で減り、深夜の場面では残量わずか＋充電中表示になります。夜の場面では画面の色温度がわずかに落ちます。着信・通知・返信の着信では、対応端末で軽く振動します（navigator.vibrate）。
15. **世界の時間経過（v6）**：Instagramのフォロワー数・いいね数は章をまたぐと少しずつ増え、投稿へのコメントも時間差で追加されます（友人・ソルアたちの短いコメント）。カカオの友達一覧には、誕生日の章で「생일인 친구（誕生日の友達）」表示が出ます（2021年当時のカカオ仕様）。
16. **写真アプリ（v6）**：ホームに「사진」アプリを追加。物語の中で撮った写真が、日付（韓国式）付きで進行に合わせて増えていきます（バーの夜、作業室、誕生日の蝶、合宿の観覧車、雨の夜、修復の日々、ギャラリー展……）。タップで大きく表示されます。
17. **通話の痕跡（v6）**：電話アプリの履歴に、通話時間（06:12／03:47）が残ります。さらに雨の章を過ぎると、あの夜の「부재중 전화（不在着信）― 6월 26일 오전 2:47」が1件だけ履歴に残っています。本編の文面には触れていない、履歴だけの痕跡です。
18. **効果音と生活音（v7）**：カカオの送受信音・通知音・着信音・雨音やバーの環境音などを、すべてオリジナル合成音で実装。ホームの演出設定で効果音ON/OFF・効果音量・全体ミュートを変更できます。
7. 進行状況はブラウザの localStorage に自動保存されます。ホームの「最初から」でリセットできます。
8. **v1のセーブデータからはそのまま継続できます**（第1部完のセーブは、第2部の開始地点として自動で引き継がれます）。

大人の場面は描写なしのフェードアウトのみで表現しています。

## 造形について
- ジェオンは「核心を言い切らない。質問返し・笑い・沈黙・すり替えで濁す。好意は言葉ではなく行動で示す（好みのライムの飲み物、薬とお粥、迎えに来る）。失いかけて初めて動く」という原作分析に基づく造形で統一しています。

## 技術メモ
- `index.html` 単体＋ `assets/` 画像のみ。ビルド不要。
- 検証：Playwright＋Chromium（390px幅）で通しプレイ検証済み。v2では3エンディング全てへの到達、解剖メモ全9件の解放、v1セーブ（第1部完）から第2部への継続を実地確認し、JSエラー0件でした。
- v2の追加画像（雨の夜のスチール／彼の近況写真）もPinterest等で公開されていたファン素材から取得し、目視確認のうえ使用しています。
- 選択肢の二重表示を防ぐガードを追加しました（▶ボタンの連打対策）。
- ボイスは未収録です。通話はテキスト通話UIのみ。音声を追加できるよう、通話は独立したシーン構造になっています。
