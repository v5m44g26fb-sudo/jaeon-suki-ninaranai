# 🦋 パク・ジェオンを好きにならない件

韓国ドラマ『わかっていても』（알고있지만、）の世界を題材にした、スマホ風SNSファンゲーム（単一HTML＋画像アセット、フレームワークなし）。

**これは二次創作のファンメイド作品（創作フィクション）です。原作ドラマ・放送局・出演者等の実在の人物・団体とは関係ありません。**

▶ **プレイ:** https://v5m44g26fb-sudo.github.io/jaeon-suki-ninaranai/

## あらすじ / 第1部の範囲
主人公はホンソ大学彫塑科4年の「なお」（ユ・ナビの位置）。元彼の個展で破局した夜、バーで蝶のタトゥーの男――パク・ジェオン（彫塑科2年、再受験＋休学で同い年）と出会う。
- プロローグ：元彼の個展／破局
- 第1章：バーでの出会い（コースターの蝶、「蝶、見に行く？」）
- 第2章：学科の飲み会で再会、作業室、カカオトーク開始
- 第3章：曖昧な関係の始まり〜なおの誕生日〜一度目の別れ（「いつも壁を作ってる」）→ 第1部完

## 遊び方 / システム
1. ホーム画面から「カカオトーク」を開き、パク・ジェオンのトークを開くと物語が自動で進みます。
2. なおの返信は3択式。選択でパラメータ「解明度」と「心の距離」が変動します。試す・採点する・理由を聞く（ENTP-T的）返しほど、彼の仕組みが見えてきます。
3. **解剖メモ**：各章のキー場面で、彼の心理を分析したメモが解放されます（全5件）。壁の正体、感情と言語化のズレ、間欠報酬など。
4. Instagram：ジェオンとなおの投稿が物語の進行で解放されます（投稿をタップすると詳細・コメント表示）。
5. カレンダー：3月〜7月の一学期タイムライン。進行に合わせて解放。「兵役：未定の予定」という小ネタも……。
6. 友人ビンナ／彫塑科グループ／ドヒョクのトークは読み取り専用のサイド要素です（友人トークは短め）。
7. 進行状況はブラウザの localStorage に自動保存されます。ホームの「最初から」でリセットできます。

大人の場面は描写なしのフェードアウトのみで表現しています。

## 造形について
- ジェオンは「核心を言い切らない。質問返し・笑い・沈黙・すり替えで濁す。好意は言葉ではなく行動で示す（好みのライムの飲み物、薬とお粥、迎えに来る）。失いかけて初めて動く」という原作分析に基づく造形で統一しています。

## 素材・クレジット
- **登場人物の画像**（ジェオン／ドヒョク／ソルア／ビンナのアイコン、ジェオンのInstagram投稿写真、雰囲気写真）は、Pinterest等で公開されていたファン素材を検索経由で取得して使用しています。ファンメイドの二次創作の範囲で使用しており、権利は各権利者に帰属します。問題がある場合はご連絡ください（対応します）。
- **なおのアバター・投稿写真**は、制作者が本人から提供を受けた既存素材（従来作『熱愛バレた件』等で使用許可済みの写真）を流用しています。本人の明示的な許可に基づくもので、他の人物の写真を「なお」として使うことはしていません。
- **UIの参考元**：カカオトーク風チャットUIの配色（黄色 #FEE500 基調）・レイアウト感は、MITライセンスの公開アプリ [Virtual Phone Studio](https://github.com/omowomomo/tws-virtual-phone-studio)（omowomomo）を参考にし、コードはコピーせず単一HTMLで自作実装しています。同リポジトリのアイコン・サンプル素材は使用していません。
- **土台エンジン**：自作ゲーム『熱愛バレた件』『担当をデビューさせる件』系の単一HTMLスマホ枠エンジンの構造を参考に、本作用に新規に軽量実装しました。
